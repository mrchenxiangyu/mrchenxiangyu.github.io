# 陈翔宇的个人主页 🌟

这是我的个人主页，使用 **GitHub Pages** 免费托管。

## 🔗 访问地址

👉 **[https://mrchenxiangyu.github.io/](https://mrchenxiangyu.github.io/)**

## 📁 项目结构

```text
├── index.html          # 主页源码（单文件，纯 HTML/CSS/JS）
├── files/
│   ├── README.txt      # 简历文件放置说明
│   ├── resume-zh.pdf   # （可选）中文简历，需自行上传
│   └── resume-en.pdf   # （可选）英文简历，需自行上传
└── README.md           # 本说明文件
```

## ✏️ 如何修改

1. **内容修改**：直接编辑 `index.html`，搜索 `TODO:` 注释即可找到需要替换真实信息的位置（联系方式、经历、项目等）。
2. **上传简历**：将简历 PDF 命名为 `resume-zh.pdf` / `resume-en.pdf` 放入 `files/` 目录。
3. **添加项目链接**：在 `index.html` 的项目卡片中，将 `<span class="badge">筹备中</span>` 替换为真实项目链接即可。

## 🚀 如何部署更新

推送到 `main` 分支后，GitHub Pages 会自动重新构建并生效（通常 1~2 分钟内）：

```bash
git add .
git commit -m "更新个人主页"
git push origin main
```

> 注意：`<username>.github.io` 仓库必须为**公开**，别人才能访问你的主页。
